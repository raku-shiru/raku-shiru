# SEO / GEO ガイド

- すべての公開ページに固有タイトル、description、canonical、適切なH1、関連内部リンク。
- `lang="ja"`、日本語の語順、意図に合う見出しを優先。
- トップページはWebSite、記事はBlogPostingとBreadcrumbListを内容に一致させる。
- 架空の評価・価格・レビュー・実績・人物プロフィールの構造化データを作らない。
- `robots.txt` と `sitemap-index.xml` が本番URLを指すことを確認。
- `SITE_URL` をカスタムドメインに変更したら再ビルドし、canonicalとsitemapも変更。
- GEOは独立した魔法のタグではない。明確な回答、一次情報、比較表、信頼できる引用、構造化されたHTMLで支える。
- `llms.txt`は必須ではない。目的と検証計画ができるまで追加しない。
- アフィリエイトリンクには `rel="sponsored"`。契約前に広告提供元の条件を確認。
- 読者が訪問する意味のない薄いページを量産しない。
