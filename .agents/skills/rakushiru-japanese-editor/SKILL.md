# ラクしる：日本語編集スキル

## ブランドの声
親しみやすく、わかりやすく。押しつけない。読者の時間を尊重する。

- 書き言葉は自然な `です・ます` 調。丁寧だが堅くしない。
- 読者の具体的な迷いから始め、結論を早めに伝える。
- 比較は「向いている人・向いていない人・確認事項」を含める。
- 漢字の連続を避ける。ひらがなで柔らかさを出すが、幼くしない。
- 文章の長さを変えてリズムをつける。不要な感嘆符や誇張を避ける。
- 「劇的に変える」「必見」「圧倒的」「今話題」など根拠のない宣伝文句を使わない。
- 一人称の体験談・口コミ・専門家コメント・試用写真を作らない。
- AIで文章を作っても、人間が使ったかのような表現を入れない。

## 執筆前チェック
1. 検索意図：読者は何を判断しようとしているのか。
2. 対象範囲：記事が答える質問と、答えない質問を決める。
3. 一次情報：公的機関・公式サイトを優先し、情報の日付を確認する。
4. 価格・提供地域・返金条件などは変動しやすいため、確認済みのときだけ書く。
5. 内部リンク：内容がつながる記事だけを自然に案内する。

## 編集の7パス
1. 読者の質問に答えているか
2. 比較に偏りや曖昧さがないか
3. 日本語が自然か（直訳・定型文・意味のない接続詞の除去）
4. 見出しと文章の流れがわかりやすいか
5. 重複した言葉・助詞・言い回しがないか
6. 出典・事実・日付の整合性
7. 表示広告・PRの透明性と行動の押しつけがないか

## 出力要件
- title / description / publishedAt / category / readingMinutes を持つMarkdown。
- 検索結果向けの紹介文は自然な日本語で約70〜120字を目安にし、むやみに文字数を埋めない。
- Markdownの見出しはH2から始める（ページにH1がある）。
- 実際に内容を更新したときだけupdatedAtを設定する。
- アフィリエイト広告を含む場合に限り `sponsored: true` と実際の広告リンクを配置する。
- 実行可能なら `npm run lint:ja` と `python3 scripts/check_content.py` を実行。改善が必要な点を報告する。
